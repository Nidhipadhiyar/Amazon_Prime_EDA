# Amazon Prime TV Shows and Movies - EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on Amazon Prime TV Shows and Movies data.

The analysis focuses on understanding:
- Content diversity
- Regional availability
- Trends in content over time
- IMDb ratings and popularity

## Dataset

The project uses two datasets:

- `titles.csv` - Contains information about Amazon Prime movies and TV shows.
- `credits.csv` - Contains information about actors and directors associated with each title.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Analysis

The EDA explores:
- Movies vs TV Shows
- Content growth over the years
- Popular genres
- Production countries
- Age certifications
- Runtime distribution
- IMDb and TMDB ratings
- IMDb votes and popularity
- Number of seasons in TV Shows
- Relationships between numerical variables

## Project Files

- `amazon_prime_EDA.ipynb` - Main EDA notebook

## Conclusion

The analysis provides insights into the content diversity, regional distribution, growth trends, and rating patterns of the Amazon Prime content library.
